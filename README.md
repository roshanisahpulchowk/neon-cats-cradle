## ✨ Features

| | |
|---|---|
| 🖐️ **2-Hand Tracking** | Real-time finger landmark detection |
| 💡 **3 Visual Modes** | String / Particles / Waves |
| 🎨 **3 Color Palettes** | Cyan/Pink · Green/Purple · Orange/Blue |
| 🌀 **Harmonic Wiggle** | Organic oscillation effect |
| 🔄 **Symmetry Mirror** | Kaleidoscopic mirrored visuals |
| 📹 **Screen Recording** | Capture + mic audio, auto-downloads WebM |
| 📱 **Mobile Friendly** | Touch controls included |

---

## 🎮 Controls

| Key | Action |
|-----|--------|
| `SPACE` | Cycle color palette |
| `M` | Cycle visual mode |
| `L` | Toggle harmonic wiggle |
| `K` | Toggle mirror symmetry |
| `R` | Start/stop recording |
| `H` | Help overlay |
